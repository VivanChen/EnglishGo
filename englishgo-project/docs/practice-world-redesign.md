# 小任務與複習流程

本輪改善單字測驗、聽寫與「再練一次」三項功能，沿用既有小學、國中、高中教材與語音服務。

## 單字小任務

- 先選擇英選中、中選英或交替練習，再開始 5／10 個單字的小任務；不計時。
- 先用內建字庫準備題目，雲端字庫可補充後續的新任務。已開始的題目不會因雲端回應而改變。
- 題目去除重複單字與重複選項，中選英不會把中文意思完全相同的另一個單字當成錯誤選項。
- 答錯可以核對既有例句、重試或先記下來。完成頁分別顯示練習數量、首次答對及曾經答對的數量，不把重試當成首次就答對。
- 可以只練錯過或使用過提示的題目，也可以將這些單字直接交給既有單字卡複習。

## 小耳朵練習

- 每次 3／5 句，選擇點選單字組句或自行打字；小學預設點選模式。
- 孩子主動按播放才會朗讀，支援放慢、停止與重聽。離開分頁會回到可繼續練習的入口，並停止朗讀。
- 依原句製作單字積木，相同單字有不同識別碼；點選已放入句子的積木可收回。
- 比對忽略大小寫、標點與多餘空白。逐字對齊顯示漏掉及多寫的字，避免漏一字後把整句都標錯。
- 句子提示、重試與只練需要再看的句子都可使用。沒有改動原有 TTS 提供者，也沒有在其他功能套用字典專用的 Web Speech 規則。

## 複習花園

- 字義優先使用既有本地字庫，再補充擴充字庫與雲端資料；缺少字義時說明現況，提供單字搜尋入口。
- 支援英文／中文搜尋、五張短複習、翻開核對意思、保留再練，以及交給既有單字卡。
- 每輪固定複習順序，記住並移出一個單字時不會跳過下一張。先翻卡、且有可用字義，才能選擇「記住了」。
- 清空操作收在清單管理中，需再次確認並可取消。記住或清空後可復原最近一次移除；只影響目前年級，復原不覆蓋較新的練習次數。

## 保存與獎勵

測驗與聽寫分別以 `eg_practice_quiz_<level>`、`eg_practice_listening_<level>` 保存目前任務，包含題目、輸入、進度、首次作答、提示及獎勵紀錄。重新整理後可自行選擇繼續，沒有自動播放。開始新任務會取代上次進度，入口有清楚說明。舊版沒有此種任務存檔，因此沒有覆寫舊版 SRS、弱點單字或其他學習紀錄。

每份任務的每題首次答對獲得原本 10 XP，之後重試、複習或重新整理不會再領同一題獎勵。答錯後更正仍可領取該題尚未領過的獎勵；首次成績保持不變。小測驗全部首次答對且未用提示，才觸發原有全對成就。聽寫完成計數每份任務只觸發一次。新任務仍可正常累積學習獎勵。

本機儲存不可用時仍可完成當次練習，畫面會說明無法保存。清除瀏覽器資料會移除新任務進度，沒有新增雲端同步。

## 維護與驗證

- `src/features/LearningPractice.jsx`：測驗、聽寫、保存與 App 獎勵串接。
- `src/features/ReviewGarden.jsx`：複習清單與固定卡片流程。
- `src/data/practiceJourney.js`：選題、逐字比對、狀態變化、存檔驗證與年級隔離。
- `src/components/PracticeArt.jsx`、`src/practice-world.css`：本地 SVG 插畫、手機版面、深色模式及減少動畫。
- `scripts/qa-practice-world.mjs`：1440／390／320px 實際作答、續練、錯題重練、單字卡串接、聽寫積木、逐字回饋與複習流程。

執行 `npm test`、`npm run build`、`git diff --check`。瀏覽器檢查預設連線 `http://localhost:5190/`；可用 `QA_URL` 更改，`PLAYWRIGHT_MODULE` 可指定已安裝的 Playwright 模組。輸出保存在 `.superpowers/qa/practice/`。

本機 Vite 不提供 Netlify 雲端語音函式，其請求另行記錄；實測本機語音控制與失敗提示，不代表正式環境雲端朗讀已驗證。本次尚未推送或部署。

### 本輪驗證結果

- 全套測試 28 個檔案、378 項通過；最後補上教材欄位保留與存檔檢查後，相關 16 項測試再次通過，沒有未處理錯誤。
- 新流程在 1440／390／320px 共 77 個畫面檢查通過，涵蓋實際作答、重試、重新整理、無重複獎勵、深色模式與單字卡入口。
- 國中、高中另以 320px 驗證 10 題測驗、5 句聽寫、續練與長句顯示，共 6 個畫面通過。
- 最後從測驗錯題實際進入單字卡、翻面並展開補充用法，確認詞性、字形變化與常見搭配保留。
- 全站回歸記錄 141 項畫面與流程檢查，未發現超寬、失效圖片或 JavaScript 錯誤。正式建置與 `git diff --check` 通過。
