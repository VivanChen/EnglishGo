# 寵物系統重新設計

寵物小家園是所有活動的入口，依孩子的下一步安排資訊：先有夥伴，再照顧、學英文、一起出遊，最後查看成長與收藏。扭蛋、遊樂園、森林遠征和島嶼大富翁各自有完整的準備、遊玩與結算畫面。

## 小家園與新手流程

六個分頁為「小家園、我的夥伴、一起出遊、孵化小屋、每日任務、夥伴圖鑑」。首頁優先提示可孵化的蛋、可領的每日任務或夥伴當前需要，金幣餘額與儲存方式保持可見。

- 沒有寵物與蛋的新玩家，可以免費選一顆小兔、小雞或小狗的蛋，並取得三份蘋果。完成三次學習進度即可孵化，首次領養不能重複領取。
- 所有蛋一起累積學習進度。進度未滿時直接前往單字複習；可以孵化時顯示明確按鈕，孵化完成可直接照顧新夥伴。
- 本機模式記住選擇。帳號同步是設定中的可選功能；登入、註冊與資料合併保留，畫面清楚說明本機資料與雲端帳號的關係。
- 圖鑑可搜尋並切換已擁有、孵化中與未收集。每個狀態有對應入口，避免只展示無法操作的清單。

## 照顧、商店與每日任務

餵食先選庫存食物，再完成一句英文互動；完成才扣除一份食物，取消不扣除。商店的購買、售價、庫存、餵食效果與英文朗讀分開呈現。

每隻夥伴每天首次完成每種照顧，可獲得金幣 +5 與寵物 XP +10；讀書改為 XP +30、親密 +15，玩耍另加親密 +10、體力 −5。當天完成三種不同照顧，額外獲得金幣 +20、XP +30、親密 +10。重複照顧仍可餵食或清潔，但不重複發成長獎勵。

休息每天首次恢復 25 體力，離線每小時恢復 8 體力，上限 100。飽足與清潔的離線下降最多計算八小時，降至 20 後不再因離線繼續扣除；排泄物數量有上限。每日任務明示完成進度、實際獎勵及前往練習或照顧的入口，並防止連點重複領獎。

原有等級、經驗、親密、技能、培育方向、陪伴印記與家園風景保留，整理在夥伴頁面中。小兔等九種既有向量插畫繼續使用，蛋改為完整的向量插畫，其餘物種保留既有專屬圖像。

## 森林扭蛋屋

抽取前顯示單抽／十連抽的費用與餘額，不足時可直接前往每日任務。單抽 50、十連抽 500 金幣，保留既有機率、十抽 R 以上及二十抽 SR 保底規則。

獎勵先結算再播動畫；動畫可略過，離開或重新載入不重複扣款或發獎。最新結果可重新查看，按實際狀態前往孵化小屋或照顧夥伴。抽到重複寵物的補償有明細；同種蛋已滿進度時保留重複抽取的補償，孵化後一併套用。

## 一起出遊

| 活動 | 重新安排的流程 | 進度與獎勵 |
| --- | --- | --- |
| 夥伴遊樂園 | 選 1–2 位夥伴 → 選野餐接力或記憶尋寶 → 選關卡 → 三回合 → 成果與單字複習 | 每款三關逐關解鎖；記錄最佳星星，每位夥伴每天每款首次完成才發成長獎勵 |
| 森林遠征 | 選隊伍 → 準備照顧與補給 → 答題戰鬥 → 關間營地 → 戰鬥 → 結算 | 顯示問題、隊伍體力與敵人體力；保留關卡、魔王、技能和培育效果；中途離開可回到本次遠征 |
| 島嶼大富翁 | 選 6／10 回合與同行夥伴 → 免費出發 → 擲骰、答題、買地 → 完成旅程 | 島嶼旅費獨立於主錢包；完成後固定獎勵 12 金幣，每答對一題再加 2 金幣，一次存入主錢包 |

遊樂園不限時，記憶題先讓孩子看清楚路線，答錯可再試、可看提示；暫停與離開的影響有明確說明。每位夥伴每天每款首次完成獲得寵物 XP +18、親密 +8、陪伴印記 +1，體力 −4；當局有首次完成的夥伴時，另發金幣 +8。重玩可改善星星紀錄。

遠征營地一次選一種補給：恢復 25% 體力、下一關答對傷害 +12，或下一關反擊傷害 −8。最後一關必須確實擊敗敵人才通關。結果出現前完成一次結算，重新查看結果不再發獎。照顧與補給遵循小家園相同規則。

大富翁可暫停移動與電腦回合；答錯後先看正解，再主動繼續。結束或破產不扣除主錢包，剩餘島嶼旅費也不兌換主金幣。答題 XP 照常推進學習與孵化，避免 XP 附帶的隱藏金幣使結算與餘額不一致。

## 舊存檔與資料一致性

- 登入合併使用金幣與各食物數量的較大值，不相加，避免重複登入產生資源。
- 寵物保留較佳成長與各關最佳星星，日常紀錄統一比較日期格式，避免新舊存檔重複取得當日獎勵。
- 保存已孵化蛋的 ID，阻止舊雲端快照重新加入已消耗的蛋；沒有可識別 ID 的歷史資料保留，以免遺失進度。
- 離開登入頁、切換流程或卸載頁面後，過期的登入請求與密碼雜湊結果不能覆寫目前的帳號狀態。

## 驗證方式

```powershell
npm test -- --maxWorkers=2
npm run build
git diff --check
$env:QA_URL='http://127.0.0.1:5194/'
node scripts/qa-pet-world.mjs
```

完整寵物巡檢會依序執行以下腳本，避免同時啟動多個瀏覽器造成資源競爭。環境沒有本地 Playwright 套件時，可透過 `PLAYWRIGHT_MODULE` 指定現有 Playwright 模組路徑。

| 腳本 | 真實瀏覽器驗證 |
| --- | --- |
| `qa-pet-redesign.mjs` | 家園、照顧、食物購買、每日任務、孵化、圖鑑、遊戲入口與深色模式 |
| `qa-pet-onboarding.mjs` | 首次本機使用、免費領養、完成三次實際單字複習、孵化與重新載入 |
| `qa-pet-account.mjs` | 登入／註冊表單、PIN 驗證、返回本機、設定入口與深色模式；不呼叫真實帳號服務 |
| `qa-pet-gacha-redesign.mjs` | 單抽／十連抽、餘額不足、動畫略過、重複結果、恢復與深色模式 |
| `qa-pet-playground.mjs` | 兩款遊戲三個關卡、答錯／提示、暫停、解鎖與每日獎勵上限 |
| `qa-pet-expedition.mjs` | 完整遠征、兩次營地、暫停／離開恢復、結果重新載入與深色模式 |
| `qa-pet-monopoly-journey.mjs` | 免費出發、完整回合、答錯／正解、買地／租金、暫停、結算與深色模式 |

桌面 1440px、手機 390px 與窄手機 320px 檢查會保存截圖與 JSON 報告於 `.superpowers/qa/`，檢查頁面錯誤、橫向溢出與失效圖片，並人工查看關鍵截圖。單元與元件測試另驗證每日獎勵、資料合併、帳號流程、重複點擊與恢復後的一次性結算。

本次全站測試 47 個檔案、566 項通過，正式建置與 `git diff --check` 通過。遊樂園實際完成 19 局、57 回合；遠征與大富翁均包含完整結算。最後補驗大富翁完成使陪玩任務增加一次，中途退出不增加；深色帳號提示的文字對比也已重新檢查。

雲端登入使用模擬回應驗證，沒有使用真實帳號測試雲端同步。本機 Vite 不提供 Netlify 雲端朗讀函式，其請求另行記錄；既有語音服務保留。上述驗證於本機完成。
