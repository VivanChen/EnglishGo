# 翰林單字卡水彩圖片修訂

本次將 Here We Go! 第 1–8 冊與 Hooray ABC Review 的 665 筆課程卡片，統一使用 EnglishGo 原有的水彩與色鉛筆插畫風格。共 516 個圖像語意，包含天氣 cold 與感冒 cold 的不同圖片；296 張沿用已核對的 EnglishGo 插畫，220 張以內建 image_gen 製作。

15 個人名各有獨立的原創人物與生活情境，搭配對應中英例句。這些人物並非翰林教材官方角色設計。本次不變更字詞收錄範圍，也不宣稱已核實 115 學年度官方完整詞表。

圖片以既有 `public/images/vocabulary/hooray/apple.webp` 為風格參考，採自然比例、紙張質感、細緻筆觸與清楚的情境。已核對人物動作、物件數量、動物特徵及例句關係；不再以通用頭像、emoji 或 SVG 圖示充當插畫。

新檔案位於 `public/images/vocabulary/hanlin-watercolor/`，使用 768 像素 WebP。每張圖的來源、內建 image_gen 提示詞、配對例句及 SHA-256 記錄在 [圖片清單](hanlin-watercolor-art.json)。

繼續已儲存的翰林複習時，會更新卡片內容、圖片與例句，保留原本的卡片順序、複習佇列和作答紀錄。其他來源的卡片不套用這項更新。

驗證包含本機逐圖檢閱、圖片檔案格式與語意數量、15 名人名情境的獨立性、儲存進度更新、SRS 與課程瀏覽器測試、正式建置，以及推送後正式站圖片的 HTTP 狀態、MIME 類型與 SHA-256 比對。

本次環境的瀏覽器操作被 Work 設定停用，因此沒有完成桌面／手機瀏覽器實機畫面驗證。圖片檢閱為本機圖檔檢查，線上驗證為 HTTP 與內容比對。
