# 單字探索室與 AI 家教練習簿

這一輪讓查字後的閱讀、收藏與複習更連貫，也讓 AI 家教能保存草稿與對話，安全處理停止、重試與換本。

## 單字探索室

- 中英文查詢保留原有字形比對、年級範圍與排序邏輯，先顯示已找到的字，再合併後續字庫結果。
- 查詢有六秒等待期限，編輯、換範圍、停止或離開後不再套用過期回應。限制的是等待與畫面更新，底層字庫請求不一定可取消。
- 點開單字即可查看原有字義、詞性、音標、例句與繁體中文翻譯，不編造缺少的例句。
- 提供大字閱讀與有文字標籤的朗讀按鈕；單字探索室的朗讀只使用 Web Speech。
- 最近看過保留八個字，可清除紀錄；收藏最多五十個單字，可移出、還原。
- 每頁八筆，避免大量結果形成過長列表；查無結果時提供查詢建議與恢復入口。
- 收藏中前五個有字義的字可直接進入單字卡，回到查詢頁時保留原本的草稿與收藏。收藏本身不發放 XP。

## AI 家教練習簿

- 短句、生活對話與批改先預覽問題，再主動送出；保留原有的學習、情境、批改主題，包括問路、點餐、中翻英與日記。
- 主題預覽取代草稿後可以復原先前輸入，避免原本寫的問題消失。
- 每個年級最多八本練習簿，每本二十個問題；每本獨立保存草稿與完整回答。送給 AI 的上下文只包含最近五組已完成問答與目前問題。
- 失敗、停止與重新整理後的未完成請求保留問題，不會自動重送；重試沿用同一筆問題，不把錯誤訊息當成 AI 的回答傳回服務。
- 換本、離開與停止會中止目前請求；即使來源忽略中止或稍晚才回來，也不能寫進新對話。整體等待最多四十五秒。
- Enter 用來換行，Ctrl／Command + Enter 可以送出，中文輸入法組字期間不送出。
- 最多收藏二十四段有幫助的回答，刪除練習簿不會刪掉獨立收藏；練習簿與收藏移除後都有還原入口。
- 複製失敗時保留可選取的文字，不誤顯示成功。朗讀速度可調整，完成、失敗、換本、隱藏頁面與離開時更新停止狀態。
- 未設定 AI 時仍可保存問題，提供家長設定與現有句型課程入口。填有設定不宣稱服務已連線成功。
- 沿用原本的 Gemini 模型順序與參數、全站 Key 和家教朗讀管線；沒有新增 AI 供應商或變更模型。

## 儲存、視覺與驗證

- 新增年級分開的本機鍵 `eg_word_explorer_<年級>` 和 `eg_tutor_studio_<年級>`，不會同步到其他裝置。儲存失敗時顯示提示。
- 查字與對話使用不同的程式繪製插圖，沿用全站配色、深色模式、大按鈕與減少動畫設定。
- 長文字換行、可收合補充主題和收藏，取代把整個家教介面塞進固定螢幕高度的排版。
- 全套 423 項 Vitest 測試通過，正式建置與 `git diff --check` 通過。既有跨日測試的懶載入等待調整為五秒，避免冷啟動時過早判定失敗。
- `scripts/qa-learning-desk.mjs` 共 69 筆檢查通過，涵蓋 1440、390、320 px、深色模式、國中／高中空白狀態及無 Key 的句型入口。
- 正式建置預覽上的 `QA_FULL=1 node scripts/qa-learning-experience.mjs` 共 141 筆相鄰功能回歸通過，涵蓋單字卡、閱讀、歌曲、寵物及其他模組入口。
- 實際檢查桌機與手機截圖，沒有橫向溢出、破圖或未預期的頁面執行錯誤。
- AI 回答、503 與延遲回應採受控測試資料；Web Speech 事件使用替身驗證管線與狀態，沒有驗證真人聽感或真實 AI 品質。模擬 API 失敗另列紀錄。
- 本機預覽沒有 Netlify 雲端朗讀函式，相關 404 另列為未驗證服務，不視為成功朗讀。

上述驗證是本機結果，未包含正式站部署後的檢查。
