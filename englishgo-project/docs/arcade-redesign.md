# EnglishGo 遊戲探索島

## 玩法改版

| 遊戲 | 玩法 | 關卡變化 |
| --- | --- | --- |
| 地鼠花園 | 聽音、看中文，選擇拿著正確英文的地鼠；答對種下一朵花 | 3／4／5 個任務；第 3 關挑戰模式先聽音，提示可顯示中文 |
| 記憶星空 | 找到意思相同的英文與中文，點亮星座 | 3／4／6 組；輕鬆模式牌面全開，挑戰模式先看 3 秒再蓋牌 |
| 火箭拼字 | 用可點選的字母積木或鍵盤補充火箭能量 | 3／4／5 個單字；後面的關卡加入 1／2 個多餘字母 |
| 句子小火車 | 把單字車廂排成句子，車廂可取回、重排 | 3／4／5 句；第 3 關加入多餘車廂 |

四款遊戲均提供 3 段關卡、輕鬆練習與挑戰模式。必須主動按下開始才進入遊戲；輕鬆模式不計時。暫停會停止倒數及操作，離開瀏覽器分頁也會自動暫停，回來後由玩家按「繼續冒險」。答對後的回饋停留期間不扣時間。

入門關卡在教材充足時優先選取短的名詞、形容詞。遊戲使用既有各年級字庫、例句教材與雲端字庫回退流程；沒有新增 AI 產生的教材。英文發音沿用原本的語音服務，音效和動畫尊重全站設定。

## 回饋與紀錄

- 完成關卡獲得 1 顆星；最多 2 次失誤可再得 1 顆；零失誤且未使用提示可再得 1 顆。
- 過關開啟下一關，最佳星星與得分分別依年級、遊戲、模式保存於 `eg_arcade_progress`。
- 冒險得分與連續成功回饋獨立顯示；原本的 XP／金幣獎勵由 App 統一處理。
- 同一題或同一組配對只會發送一次獎勵。重複點擊、翻牌尚未結算、暫停、結束後的操作均由同一套狀態邏輯阻擋。
- 超時可重新挑戰，已拿到的學習獎勵不倒扣。每次新開一局仍可累積學習獎勵。
- 結算提供下一關、重玩、地圖、回首頁休息，以及本輪教材朗讀。

最佳紀錄保存在目前瀏覽器；未加入帳號同步或未完成遊戲的跨裝置續玩。

## 畫面與操作

遊戲島提供四款遊戲的插畫入口，以及寵物大富翁入口。場景、地鼠角色、星座、火箭與列車皆為本地 SVG，無外部圖片依賴。場景會配合過關進度變化，翻牌、種花和得星提供短動畫。

手機可直接點字母，不必叫出鍵盤；地鼠支援鍵盤 1–4，拼字支援實體鍵盤。配對蓋牌時不把隱藏答案放進按鈕名稱。暫停使用原生對話框，限制背景操作並提供明確的繼續與離開出口。

固定遊戲資訊列會依網站導覽列的實際高度定位，包含 320px 導覽列換行的情況。

## 維護與驗證

- `src/data/arcade.js`：選題、遊戲狀態、提示、計分與關卡紀錄。
- `src/features/ArcadeGames.jsx`：四款遊戲介面、倒數、暫停與 App 獎勵串接。
- `src/components/ArcadeArt.jsx`：共用向量插畫。
- `src/components/ArcadeDiscovery.jsx`：遊戲島與星星紀錄。
- `src/arcade.css`：遊戲主題、手機版面、動畫及深色模式。
- `scripts/qa-arcade.mjs`：透過實際教材答案在瀏覽器完成關卡，檢查窄手機、解鎖、暫停、重新載入保存與深色模式。

執行 `npm test`、`npm run build`、`git diff --check`。瀏覽器測試可設定 `PLAYWRIGHT_MODULE` 指向現有 Playwright 的 `index.mjs`，`QA_URL` 預設為 `http://localhost:5190/`。遊戲檢查輸出在 `.superpowers/qa/arcade/`；原有全站巡檢仍使用 `scripts/qa-learning-experience.mjs`。

本機 Vite 未提供 Netlify 雲端語音端點，其 404 單獨記錄為 `unavailableServices`；這不代表已驗證正式環境的雲端發音。本次未部署。
