# 小說閱讀體驗

這次改善讀到一半的接續、英文自主閱讀與章末操作，保留既有故事、英中段落對應、朗讀音檔識別與翻頁動畫。

## 閱讀流程

- 目錄與書籤可直接跳到章節或收藏段落。每本書最多 80 個書籤，可移除並還原；摘錄取自原始小說內容。
- 可選擇英中並排或先讀英文；英文模式下可單獨展開某段中文，其他段落維持原樣。
- 暖白、柔綠、夜讀、英文字體、字級、行距與中文顯示偏好會保存。段落中文的臨時展開不會帶到下一章或下次開啟。
- 頁碼選單可直接跳頁；書架顯示上次段落摘錄和章節約略閱讀時間。
- 「接著聽」從目前頁面的第一段開始，繼續英中整章朗讀。選取或點擊正文不會開始播放，使用旁邊的喇叭按鈕朗讀。
- 最後一頁顯示章末小站，連到故事測驗、完成章節及下一章。回答後可再選一次，每章完成的 15 XP 只領一次。

## 操作與狀態

- 分頁測量綁定實際章節，避免換章後沿用前一章文字；字體、翻譯與視窗改變時以段落為定位依據。
- 桌機與手機過長的單頁內容都可捲動；手機工具展開與朗讀控制不再改動書頁高度。音訊、書籤與翻譯按鈕的測量高度與實際按鈕一致。
- 朗讀回呼帶有播放序號，舊播放的取消、結束或段落事件不會覆蓋新的播放狀態。離開閱讀器時停止播放。
- 桌機選字不觸發拖曳翻頁；按鈕上的方向鍵不會攔截為翻頁。章節卡可用 Enter／空白鍵開啟，手機工具面板支援焦點循環、Escape 關閉與焦點返回。
- `eg_novelReadingPrefs` 延伸既有偏好；`eg_novelReadingProgress` 保留既有格式並使用段落定位；`eg_novelBookmarks` 按小說保存章號、段落與收藏時間；`eg_novelSelectedBooks` 按學段保存書籍選擇。
- 上述資料保存在目前瀏覽器的 localStorage，沒有新增跨裝置同步。

- 全部單元及整合測試：`node node_modules/vitest/vitest.mjs run --maxWorkers=4`。
- 正式建置：`npm run build`；格式檢查：`git diff --check`。
- `scripts/qa-novel-reading.mjs`：1440、390、320px，收藏／還原、單段中文、配色、重新載入、書籤跳轉、字級行距、章節跳轉、測驗及 XP；另檢查國中故事與高中既有備援。
- `scripts/qa-learning-experience.mjs`：相鄰首頁、SRS、字典、小說、歌曲、寵物及設定流程。
