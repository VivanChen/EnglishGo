# 小說閱讀重新設計

2026-09-07：重新設計書架、單頁閱讀器、工具與章末流程。保留故事原文、中英逐段對應、固定音檔識別、書籤、續讀與既有 XP 規則。

## 閱讀流程

- 書架集中顯示封面、完成度、開始／繼續閱讀、上次摘錄與章節列表；章節卡可用鍵盤開啟，手機採單欄。
- 桌機、平板與手機都採單頁。桌機保留適合閱讀的欄寬及章節插圖，手機正文使用剩餘螢幕空間。頁首只保留返回、目錄、偏好與工具。
- 頁尾固定上一頁、聽這一頁、下一頁。播放時在相同位置提供暫停、繼續與停止；整章與接續朗讀開始後收起工具。
- 段落旁只顯示「⋯」，開啟後可朗讀英文／中文、留書籤，或在英文模式暫時顯示該段中文。點擊正文／選字不會自動朗讀。
- 所有工具使用同一個可捲動對話框，桌機靠右、手機由底部開啟，不改變正文高度。提供目錄／書籤、偏好、朗讀、單字、插圖與測驗，支援焦點循環、Escape 關閉及焦點返回。
- 最後一頁的下一頁按鈕改為故事小測驗；答完後可完成並接下一章。每章 15 XP 只發放一次，保留重讀與更正答案。

## 分頁與保存

- 閱讀器填滿 100dvh 並保留安全邊界，閱讀期間隱藏網站頁首／頁尾及鎖住文件捲動，退出或卸載時恢復。
- 使用實際段落和正文區高度分頁，短螢幕允許一頁一段。一般段落不用向下捲動；超長段落或放大字體仍可在正文區捲動，避免裁切內容。翻到新頁時回到頁首。
- 翻頁使用短暫滑動淡入，支援按鈕、方向鍵、左右滑動，防止轉場中重複翻頁；低動態偏好縮短動畫，動畫事件缺失仍會完成轉場。
- 以段落保存位置，調整字級、中文或旋轉後仍能找到原段落，書籤跳轉會聚焦該段。
- 保存暖白／柔綠／夜讀、英文字體、字級、行距及中文偏好。已有設定保持原值，新使用者預設 18 px、1.8 倍行距。
- 延用 eg_novelReadingPrefs、eg_novelReadingProgress、eg_novelBookmarks、eg_novelSelectedBooks；保留內容版本 2 的舊進度／書籤遷移。資料存在本瀏覽器，未新增跨裝置同步。
- 未修改 TTS 供應商、中文聲線、音檔 URL／快取規則，也未改動字典的 Web Speech 發音方式。
