# 功能健康檢查（2026-09-07）

本次檢查目前工作區的 25 個功能入口，並深入操作主要學習、遊戲、寵物與工具流程。使用正式建置的本機預覽及 Edge 自動化，測試桌面 1440 px、手機 390 px 與窄螢幕 320 px；部分練習另涵蓋國中、高中入口。

## 發現與修正

| 問題 | 重現方式／影響 | 修正後行為 |
| --- | --- | --- |
| AI 故事取消失效 | 生成途中返回選角，舊請求完成後仍跳入故事，也可能覆蓋新故事 | 返回、離開模組都中止請求與重試；忽略過期回覆，並加入 60 秒等待上限 |
| AI 故事內容不完整導致白畫面 | 模擬 AI 連續回傳只有標題的 JSON；9 次重試後出現 `Cannot read properties of undefined (reading '0')` | 檢查所需頁數、每頁雙語內容及三題四選一測驗；資料不完整時保留設定畫面並提示重試 |
| 重讀後無法重新作答 | 完成三題、重讀故事再進入測驗，直接停在第三題且選項全部鎖住 | 每次進入測驗重設題號、答案及分數；同一故事已答對題目不重複給 XP |
| 整本朗讀遭自動翻頁中斷 | 頁面自動朗讀計時器及翻頁清理取消整本朗讀，無法連續讀完 | 保留跨頁朗讀工作，手動離開才清理；以四頁完整朗讀回歸測試驗證 |
| 深色模式文字太暗 | 故事重點字、朗讀反白字、返回控制及翻譯重音提示與背景不易區分 | 為這些文字加入深色模式專用顏色，保留原有按鈕底色 |

故事生成保留原有模型順序、故事提示與語音供應商。本紀錄描述本機驗證結果；正式站部署與外部服務可用性需另行確認。
