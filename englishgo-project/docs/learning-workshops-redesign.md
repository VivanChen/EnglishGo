# 文法、口說與歌曲學習優化

這一輪把三個功能改為可暫停、可重試、有明確完成點的小練習，沿用既有教材、音檔、歌詞時間與 AI 服務。

## 文法學堂

- 句型地圖呈現逐課進度，課程拆成認識句型、選選看、小挑戰。
- 完成前一步才開啟下一步；錯答有解析，可以再試。
- 每課保存答案與獎勵狀態，重新整理後可接續，答對獎勵每課一次。
- 結束後可聽完整句子、前往下一課或回首頁休息。
- AI 講解收在補充說明中，離開課程後不套用過期回應。

## 口說練習

- 先選模式與 3／5 題，再主動開始；進入頁面不自動播放或啟動麥克風。
- 練習中的題組固定，背景教材載入不會替換目前題目。
- 保留示範、慢速朗讀、音節、重音、嘴型與逐次 AI 分析。
- 結果標示為「文字符合度」，依辨識文字比對，不宣稱是聲學發音評分。
- 明確處理無聲音、權限拒絕、裝置不可用、連線失敗與錄音逾時；離開或隱藏頁面會中止辨識。
- 沒有語音辨識支援仍可自行跟讀並記錄，這種紀錄不算辨識通過、不發辨識獎勵。
- 保存辨識文字與練習結果，不保存錄音檔；同一輪的每題獎勵只發一次。重開新練習會取代上一輪。
- 完成後可只練尚未通過的題目，重新載入已通過題目可直接繼續。

## 歌曲學習

- 保留整首播放、同步歌詞、句型、單字與 Timing Lab，加入逐句跟唱頁。
- 單句示範按原始歌詞時間開始，在下一句之前暫停；循環模式只重複目前句子。
- 三句跟唱小任務可自行標記，不將自行跟唱當作辨識評分。
- 切換歌詞／填空／跟唱、換句、換歌或離開頁面時停止目前片段。
- 保存選歌、播放位置、速度、中文顯示、填空與跟唱紀錄，重新整理後不自動播放。
- 填空可錯答重試，同一首歌的同一題只獎勵一次；整首播放完成獎勵也保存防重複狀態。
- 進度條支援鍵盤操作。歌曲初始化前不覆寫已存位置；重新選取同一首歌不清空音訊長度。

## 儲存與介面

- 使用年級分開的本機儲存鍵 `eg_grammar_workshop_*`、`eg_speaking_studio_*`、`eg_song_studio_*`。
- 題目或歌曲內容改變時，相關簽章使舊進度失效；無法儲存時顯示提示，本次仍可繼續。
- 共用柔和插圖、較大的操作按鈕、可換行內容、深色模式與減少動畫設定。
- 切換步驟時保留返回、進度列與題目一起可見的捲動位置。
- 修正回歸測試發現的單字卡動畫計時器殘留：離開模組後取消吉祥物、連擊與完成動畫的延遲更新。
