# EnglishGo 學習小花園改版

## 使用方式

- 選擇小學、國中或高中，再從「今天的小任務」直接練習 5 張單字卡。
- 依學習、閱讀聽力、遊戲、寵物、工具五類探索；搜尋框可以跨類別尋找活動。
- 桌機提供側邊分類；手機顯示五個可直接點選的分類，不需要橫向滑動。
- 點左上角 EnglishGo 回到學習首頁；在首頁再點一次則回到頁首。
- 右上角可關閉遊戲音效、減少動畫、切換深淺色。選擇會保存在目前瀏覽器。
- 家長與老師設定集中於工具區和頁尾。發音設定浮動面板只在設定頁出現。

## 設計與行為

網站採奶油白、草綠色及低對比背景，搭配本地 SVG 小芽夥伴、清楚的操作圖示和一致的圓角卡片。功能、語音服務、各年級教材、雲端字庫和既有學習紀錄繼續沿用。

短任務使用內建字庫，每天固定輪換並優先選取其中較不熟悉的字。進入功能不會增加學習進度；評分行為仍沿用既有計分規則。完成後提供明確的休息出口。

登入禮物改成首頁內可自行領取的提示；新成就會在回到首頁時顯示可手動關閉的提醒，練習中不彈出視窗。減少動畫同時尊重系統的 `prefers-reduced-motion` 設定。

單字卡評分以「再看看、有點難、記住了、很熟悉」為主，保留英文及數字快捷鍵作為次要說明。快捷鍵不攔截輸入框、按鈕與其他控制項；連按不會重複計分。連擊回饋不再於 React state updater 中更新其他元件。

沒有 AI 金鑰時，卡片字典仍會顯示既有中文釋義、詞性、發音與例句。進階設定收在家長與老師說明中。字典內容發音仍使用 Web Speech；其他朗讀保留既有服務行為。

## 維護位置

- `src/components/LearningExperience.jsx`：入口、學習首頁、分類、搜尋、共用品牌和舒適度控制。
- `src/learning-experience.css`：設計樣式、響應式版面、深色模式、動畫。
- `src/data/learningJourney.js`：每日 5 張短任務選卡邏輯。
- `src/App.jsx`：接入既有資料與功能、歷史導覽、禮物、成就、偏好設定。
- `src/features/SRS.jsx`：評分操作、快捷鍵與內建字典。
- `src/App.learning.test.jsx`：新流程的整合測試。

## 第二輪優化：閱讀與分類操作

- 切換分類後直接顯示活動列表；手機可用「換個分類」回到分類列。鍵盤只會停在目前選取的分類，方向鍵仍可切換；搜尋會提示結果數，清除後焦點回到輸入框。
- 閱讀進度保存在目前瀏覽器，依小學、國中、高中分開記錄。重新整理或回到首頁再進入，會保留文章選擇與已作答題目。教材內容改變時，舊作答不會套用到新的內容。
- 閱讀文字預設 18px，可切換到 22px 大字並記住偏好；中文提示在答題前即可使用，逐句朗讀和全文朗讀沿用原本的語音服務。
- 選錯後提供原文線索與「再試一次」；完成後可以讀下一篇或回首頁休息。已領取的題目獎勵也會保存，重做或重新整理不會重複加分。
- 閱讀介面集中在 `src/features/ReadingPractice.jsx`，使用既有短文、翻譯和題目。未改動教材內容。

閱讀紀錄僅保存在目前瀏覽器，沒有新增帳號或雲端同步；清除網站資料也會移除這些紀錄。
