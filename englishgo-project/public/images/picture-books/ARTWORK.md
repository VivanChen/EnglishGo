# Woodland backdrop v2

are the 1K diffuse and OpenGL normal maps of Forest Ground 01 from Poly Haven:
https://polyhaven.com/a/forrest_ground_01 — CC0, https://polyhaven.com/license.
Downloaded through the official asset API and shipped locally.

File: woodland-v2.png. Created using the built-in imagegen tool for EnglishGo.
Used as a photographic backdrop behind live GLB models and book geometry.
