# Woodland animal assets

fox.glb, rabbit.glb and bear.glb are original EnglishGo assets generated by
`scripts/generateStorybookModels.mjs`. They contain continuous implicit-surface
body meshes, vertex-coloured coats and fine fur geometry. No third-party model
or externally hosted texture is required. Regenerate with:

    node scripts/generateStorybookModels.mjs

These are static sculptures; scene movement is applied to their parent groups.
They are not rigged or motion-captured animals.

The photographic woodland backdrop is an AI-generated environment image,
separate from the live 3D geometry. See the image directory for its prompt.
