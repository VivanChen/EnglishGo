GIPHY API Key（選用）

只有 SRS 網路動圖需要；不申請也能使用內建圖片、圖示與其他學習功能。

1

開啟 GIPHY Developers

點 Create Account。已經有 GIPHY 帳號也從同一入口進入，再選 Log In。

開啟 GIPHY Developers ↗
2

登入，或切換到「Sign Up」註冊

已有帳號就輸入 Email 與密碼登入；沒有帳號請點上方 Sign Up，按照畫面建立帳號。這裡建立的是 GIPHY 帳號，不是 EnglishGo 帳號。

3

進入 Dashboard，按「Create an API Key」

登入後若回到 GIPHY 一般首頁，請重新開啟 Developers 網站並點 Dashboard。點選頁面上方或 Your API Keys 區塊中的 Create an API Key。

4

第一頁：選擇 API，再按 Next Step

在 Create A New API Key 1/2 視窗選擇右側 API。EnglishGo 使用 API 類型；即使左側 SDK 標示 Recommended，這裡仍請選 API。確認顯示 API Selected 後，點下方 Next Step。

5

第二頁：填寫資料，建立 API Key

在 Create A New API Key 2/2 視窗依序填寫：

  • Your App Name：可填 EnglishGo Vocabulary（截圖中的 English 是名稱範例）。
  • Platform：選 Web；使用手機瀏覽 EnglishGo 也選 Web。
  • App Description：可填 Show vocabulary GIFs for English learning.，說明用於英文單字學習。

閱讀 GIPHY API Terms，確認同意後勾選，再按 Create API Key。截圖中的說明欄尚未填寫，請填完再送出。

6

看到 App created.，複製 API Key

回到 Dashboard 並看到 App created. 表示建立成功。在 Your API Keys 找到剛建立的項目，選取 API Key 欄位內的完整文字並複製，避免包含前後空白。若沒有 Copy 按鈕，可直接選取文字複製。

本教學截圖顯示 Free Beta Key Access 額度為每小時 100 次 API 呼叫；實際額度以 Dashboard 顯示為準。Upgrade to Enterprise 是升級入口，不是複製 Key 的按鈕。

7

貼回 EnglishGo，儲存並測試

回到首頁，點開 給家長與老師｜學習資源與進階設定 → API Key 設定（Gemini／Giphy），找到 Giphy API Key，貼上後按 儲存 Giphy Key。也可以從選擇年級後的「工具 → API Key 設定」進入。

儲存後開啟 SRS 單字卡查看動圖；若沒有合適的搜尋結果，仍會顯示內建圖片或圖示。Key 只儲存在目前瀏覽器，換裝置或瀏覽器時需重新設定。

常見問題排除

先看錯誤訊息中的狀態碼，再對照下面處理。

Google：沒有看到 Create API key
先確認已進入 Dashboard → API Keys。若專案屬於學校或公司，可能沒有建立 Key 的 IAM 權限；請改選自己的個人專案，或請專案管理員授權。專案沒出現時，到 Projects → Import projects 匯入。
Google：顯示 403、PERMISSION_DENIED 或 Key 無效
重新建立一組 Auth key 並更新 EnglishGo。Google 正在淘汰 Standard key；另外也請確認已同意服務條款、所在地支援 AI Studio，且專案沒有組織政策限制。
Google／GIPHY：顯示 429 或暫時無法使用
這通常是短時間呼叫過多。請先停止連續重試，稍後再試。GIPHY beta key 上限為每小時 100 次；Google 額度則依模型、專案與目前方案顯示為準。
GIPHY：登入後找不到 Dashboard
重新開啟 developers.giphy.com，再點頁面上方 Dashboard。一般 giphy.com 是搜尋 GIF 的網站，不是開發者 Key 管理頁。
手機換一台後，為什麼 Key 不見了？
Key 只保存在當下瀏覽器，因此換手機、換瀏覽器、使用無痕模式或清除網站資料後都要重新貼上。這是刻意的隱私設計。
💳 不必為了建立 Key 直接開通付費。Google AI Studio 若出現「Set up billing」，那是升級付費方案的入口，不是取得一般 Key 的必要步驟。是否付費請依自己的額度需求決定。
